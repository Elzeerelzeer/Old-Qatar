# أصول وموارد «قطر لوّل» (Assets Directory)

تم تجهيز هذا الهيكل المنظم لتسهيل استبدال أي صور أو ملفات صوتية بصيغ PNG أو WebP أو MP3 في المراحل القادمة:

- `/assets/village/`: صور وخلفيات مباني القرية التراثية، الأسوار، وبوابة قطر لوّل.
- `/assets/characters/`: صور وسبريتات شخصية الولد (بالثوب والغترة والعقال والحقيبة العنابية) وشخصية البنت (بالبخنق والزي التراثي).
- `/assets/souq/`: صور مقتنيات سوق لوّل (الفخار، العطارة، الأقمشة، الدلال، وركن الصقّار).
- `/assets/pearl/`: صور منطقة بحر اللؤلؤ (المحامل، أدوات الغوص، الفطام، الديين، المحار، والدانة).
- `/assets/games/`: صور ألعاب فريج الألعاب (التيلة، الدحروي، الدوامة، الصقلة، القيس).
- `/assets/majlis/`: صور مجلس لوّل (سجاد السدو، الدلة، الفناجين، المبخرة، والتمر).
- `/assets/crafts/`: صور بيت الحرف وأزياء لوّل (نول السدو، سف الخوص، البخنق، والتطريز).
- `/assets/akkas/`: صور استوديو عكّاس لوّل (كاميرا المنفاخ، خلفية البحر، البشت، والأزياء التراثية).
- `/assets/audio/`: ملفات المؤثرات الصوتية (صوت البحر، فتح الباب، خطوات الرمل، ورنات المجلس).
